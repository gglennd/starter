# TanStack Start SSR & TanStack Query Starter

A full-stack React template configured with TanStack Start, Server-Side Rendering (SSR), TanStack Query, Vite, TypeScript, and Tailwind CSS.

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Typecheck with TypeScript and build for production
- `pnpm lint` - Run ESLint
- `pnpm preview` - Preview production build locally
