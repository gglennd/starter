# Starter Workspace

This repository contains a collection of modern React starter templates and boilerplate configurations:

- **`react/`**: A standard React Single Page Application (SPA) starter template.
- **`react-router/`**: A template configured with TanStack React Router.
- **`react-start/`**: A full-stack React template configured with TanStack Start.

## Usage with tiged

You can easily scaffold a new project using [tiged](https://github.com/tiged/tiged) without cloning the entire repository:

```bash
npx tiged gglennd/starter/react my-app
cd my-app
pnpm install
pnpm dev
```

## Getting Started

Navigate to any of the template directories to explore, develop, and build applications:

```bash
cd react       # or react-router, react-start
pnpm install
pnpm dev
```
